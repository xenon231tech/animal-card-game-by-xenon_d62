# Animal Card Collection

Spin wheel game untuk mengoleksi kartu hewan. Dapatkan kartu langka, kumpulkan poin, dan bersaing di leaderboard.

## Fitur

- 🎡 Spin wheel dengan 7 kartu hewan (Ant, Mouse, Cat, Dog, Eagle, Wolf, Dragon)
- 📦 Koleksi kartu dengan sistem kelangkaan (Common, Rare, Epic, Legendary)
- 💰 Beli spins dengan USDC (Multi-chain)
- 📊 Statistik lengkap pemain
- 🏆 Leaderboard peringkat global
- 👤 Profile dengan achievement & daily reward

## Teknologi

- HTML5, CSS3, JavaScript Vanilla
- LocalStorage untuk penyimpanan data
- Vercel untuk hosting
